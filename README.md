# DMI-sourcing-wizard

Helps to set up a sourcing strategy for digital products and services in the scope of DMI.

De sourcingsmatrix van het DMI-programmabureau als invulhulp: één opdracht doorlopen en er een besluitblad uit krijgen.

**Online:** https://t-ruiten.github.io/DMI-sourcing-wizard/

## Gebruik

Open `index.html` in Chrome, Edge of Firefox — dubbelklikken is genoeg. Alles zit in dit ene bestand: geen internet, geen installatie, geen server. Ingevulde gegevens blijven in de browser (localStorage) en zijn op te slaan als Excel, JSON of Markdown.

## Let op

- Geen juridisch advies — bedoeld om inkoopbeslissingen te onderbouwen.
- `index.html` is gegenereerd door `build.py` uit `matrix.json`; die bronbestanden staan (nog) niet in deze repository.
- Bevat SheetJS (xlsx.js, © SheetJS, Apache-2.0) voor de Excel-export.
